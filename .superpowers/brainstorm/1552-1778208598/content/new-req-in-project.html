A · 项目内 chat 面板（agent 多轮澄清）

项目主页有个"提需求"按钮 / Tab，点开是跟 agent 对话的窗口。agent 自动知道当前项目 + 关联 codebase，无需用户解释上下文。spec 完成后弹"入队"按钮。沿用现有 chat 工具集，最少改动 agent 层。

C · 表单 + 侧边 AI 协助（混合）

主区是结构化表单，侧边一个 AI panel — 可以让 agent 帮你追问 / 补全 / 校对 spec_md。用户自己写得清楚就忽略 AI；不知道怎么写就让 AI 推动。最复杂但最灵活。

⚠️ 顺带要决定的

全局 /chat 入口（侧栏的"对话"）选完之后会变成 ——
· 选 A/C：保留为"项目无关的助手对话"，比如问 autopilot 自己怎么用
· 选 B：可以直接砍掉 /chat，因为 agent 工具集只在项目内被调起
